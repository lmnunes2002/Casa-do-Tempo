# Casa do Tempo 🕰️ | Desafio Técnico Front-End

> Projeto desenvolvido como parte da avaliação técnica para Cimatec Jr.

## 💻 Sobre o Projeto
A **Casa do Tempo** é uma landing page desenvolvida para uma ONG (Organização Não Governamental) fictícia, focada no acolhimento e apoio a idosos em situação de vulnerabilidade. 

O objetivo principal deste projeto foi construir uma interface web moderna, responsiva e interativa, priorizando boas práticas de estruturação de código, acessibilidade e manipulação do DOM sem o uso de frameworks (Vanilla).

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estrutura semântica rigorosa, aprovada no validador W3C, garantindo melhor SEO e acessibilidade.
* **CSS3:** Estilização componentizada, layout responsivo (Mobile First) e uso de variáveis para controle de temas.
* **JavaScript (ES6+):** Lógica de interface e interatividade puramente em Vanilla JS.

## ✨ Destaques Técnicos (Features)
* **Dark Mode:** Sistema de alternância de tema (Claro/Escuro) com atualização dinâmica de ícones na interface.
* **Menu Hambúrguer Responsivo:** Navegação adaptável para dispositivos móveis, com fechamento inteligente ao ancorar nas seções.
* **Carrossel Infinito Autônomo:** Slider da seção de voluntários construído do zero com JS, utilizando transições suaves e manipulação de nós (`appendChild`) para um loop contínuo e sem quebras visuais.
* **Formulário de Doação Dinâmico:** Interface inteligente que revela campos ocultos dependendo da seleção do usuário e utiliza validações nativas do HTML5.
